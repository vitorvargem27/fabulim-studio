## Armadilhas (já custaram tempo)
- O git recusa o repositório (propriedade duvidosa): usar `git -c safe.directory=C:/video_create_ai ...` por comando; **não** mexer na config global.
- Nunca usar `Remove-Item` em arquivos do projeto (a ferramenta bloqueia); apagar por Python (`os.remove`) e pôr o que sobra no `.gitignore`.
- Não usar `Set-Location` em comandos da ferramenta. `diagnostico.ps1` precisa de **UTF-8 com BOM** (PowerShell 5.1). Na saída do Playwright, redirecionar para arquivo (não canalizar para `Select-Object -First`, que mata o processo).
- Hook do git rodado por shell MSYS (Git Bash) troca `TEMP` por `/tmp` e o pytest perdia o acesso à pasta temporária real (123 erros de fixture). Por isso o `testar` usa uma pasta temporária **própria dentro do projeto** (`tmp/testar-<pid>`, ignorada pelo git e apagada no fim).
- `cmd /c "iniciar.bat ..."` capturado por pipe trava, porque o servidor herda o cano; para automatizar use `Start-Process ... -RedirectStandardOutput` e `WaitForExit`. `Remove-Item` em comando com caminho do projeto é bloqueado pela ferramenta: limpar com Python.
- A 8000 está ocupada por outro processo do sistema (não é do Fabulim): por isso a 8765.
- Painel de navegador oculto não avança transições de CSS: conferir movimento com o Playwright.
- A CSP estrita bloqueia o `onload` inline do CSS crítico do Angular: `inlineCritical` fica **desligado** (D-023), com teste.
- Tailwind: classes de `display` (`flex`, `hidden`…) num **host de componente** brigam com as do pai (o logo da barra aparecia duas vezes): embrulhar o componente num `<span>` e pôr as classes no invólucro. Nome de classe montado por texto não é gerado: escrever a classe inteira no código.
- Foco: o anel comum é de tinta e some sobre a barra lateral (também de tinta); há regra própria em `.sidebar :focus-visible` (D-036).
- No E2E o servidor usa `FABULIM_TOOLS_DIR` e `FABULIM_MODELS_DIR` próprios (`data/e2e/…`, vazios); a instalação de verdade é **simulada** com `page.route`, para o teste nunca baixar nada.
- Máquina lenta (CPU a 100 %): comandos longos no Bash estouram o tempo; usar PowerShell com a saída em arquivo (`*> tmp\x.txt`) e `run_in_background`. O verificador de comandos às vezes responde "sem veredito": tentar de novo ou seguir com edições de arquivo.
- Em heredoc de Python pelo Bash, `\\` chega como `\` e vira caractere de controle (`\f`, `\b`): para escrever barra invertida use `bytes([92])` ou `chr(92)`. Foi assim que o caminho `tools\ffmpeg\bin` saiu corrompido no `.ps1` (corrigido).
- Só editar `diagnostico.ps1` por **bytes** (Python), para não perder o BOM UTF-8.
- **Playwright e o `fab-section`**: o `headingId` vira o `id` do **`h2`**, não do bloco; para achar o bloco use `section[aria-labelledby="<id>"]` (helper `secao()` em `frontend/e2e/ferramentas.spec.ts`). Campo obrigatório tem `*` no rótulo: `getByLabel(..., {exact: true})` não acha, use `getByRole('textbox', {name: ..., exact: true})`. O texto de dois elementos vizinhos (`<strong>` e `<span>`) não tem espaço entre eles: filtre por um pedaço só.
- O E2E das ferramentas roda **em série** (`test.describe.configure({mode: 'serial'})`): um teste falho pula o resto, e cada rodada leva ~5 min. Rode `node e2e/preparar.mjs` antes de cada execução (zera `data/e2e-ferramentas`). O axe logo depois de um clique pode pegar o `hover`: os testes que andam pelas etapas usam `reducedMotion`, e o CSS da barra de etapas já tem a regra certa.
- **Corrida evento × resposta**: o SSE (`media.deleted`, `media.created`) costuma chegar **antes** da resposta HTTP do mesmo pedido. Quem mexe em contador de lista deve descontar só se o item ainda estava na lista (`forget()` em `imagem.page.ts` e `clipes.page.ts`), senão conta duas vezes.
- O **ffmpeg falso** dos testes (`FfmpegFalso.rodar`) não pode gravar quando a saída é `-` (senão aparece um arquivo `-` na raiz do projeto; apagar por Python e conferir o `git status` depois de rodar os testes).
- `Bash` com a máquina carregada estoura os 30 s até em `grep`: usar as ferramentas Grep e Read, ou PowerShell em segundo plano com a saída em arquivo. O `cd` do Bash muda o diretório da sessão: use caminhos absolutos.
- Plural nas traduções: `{n#singular|plural}` (o `t()` escolhe pelo valor; sem o parâmetro o texto sai como está). Nunca escrever `cena(s)`.
- O modelo de texto é o **Ollama** do Vitor (`qwen3:4b`). Sem ele todo passo tem o modo sem IA, e o botão com IA mostra o motivo (503 em português), por isso o E2E não precisa do Ollama.
