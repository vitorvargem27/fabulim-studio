# Marca (gerado)

Esta pasta é preenchida por `frontend/scripts/copiar-marca.mjs` (roda antes do `npm start` e do `npm run build`).
**Não edite aqui**: coloque os arquivos oficiais em `marca/`, na raiz do projeto:

| Arquivo | Uso |
|---|---|
| `fabulim-icone.svg` | favicon, barra lateral recolhida |
| `fabulim-icone-512.png` | ícone em PNG |
| `fabulim-logo.svg` | logo horizontal para fundo claro |
| `fabulim-logo-escuro.svg` | logo horizontal para fundo escuro |

Sem esses arquivos a interface mostra o nome em texto (Fredoka). O logo não é redesenhado nem alterado.
